# Wexner 评分（大便失禁）

[条件、来源与许可](https://elucenia.org/zh/tools/escore-de-wexner)

## 使用方法

在门户中使用工具，或通过本地 HTTP 服务器打开 index.html。选择语言，填写各字段，然后计算。

## 输入与单位

`solido`

- `0` — 从不
- `1` — 很少（每月少于1次）
- `2` — 有时（每周少于1次，每月1次或以上）
- `3` — 经常（每天少于1次，每周1次或以上）
- `4` — 总是（每天1次或以上）

## 方法版本

Cleveland Clinic/Wexner Jorge 1993：5项0–4，总计0–20；粪失禁

## 已记录的公式

5项各按频率计0至4：从不（0）；很少，每月少于1次（1）；有时，每周少于1次且每月1次或以上（2）；经常，每天少于1次且每周1次或以上（3）；总是，每天1次或以上（4）。

总分0（完全控制）至20（完全失禁）。

## 限制与适用人群

患者报告的粪便失禁严重程度不能定义病因或治疗。原始综述强调治疗前的病史、检查和生理功能评估。量表及频率选项应按所用版本实施；总分不能代替肛门直肠功能评估。
